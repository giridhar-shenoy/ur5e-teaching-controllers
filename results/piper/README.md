# Real-arm measurements (AgileX Piper-H)

The data behind "On a real arm" in the top-level README: `handguide_2026-11-05.csv` (the two 30 s zero-stiffness holds and the median firmware torque gain tau/t_ff per joint) and `track_line_2026-11-06.csv`, `track_line_fast_2026-11-06.csv` (each straight-line run: gains, joint RMS and max error in degrees, the tool's RMS and max distance off the commanded path in mm, how it ended; the first run's path figures were computed afterwards from its logged ticks, the others are the run's own path report).
They come from the author's private Piper stack, not from code in this repository, and are not regenerated by any script here.
Measured 5–6 Nov 2026 on a left Piper-H arm, firmware S-V1.8-6.
