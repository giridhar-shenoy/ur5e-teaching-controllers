# scripts

Every number and every GIF in the top-level README must be produced by a script in this
directory. `regenerate_all.sh` runs all of them in sequence. If a number cannot be regenerated by
a script here, it does not belong in the README; in `docs/`, such a number may appear only in
the appendix of [docs/what_broke.md](../docs/what_broke.md#appendix-hand-recorded-runs-not-regenerated-by-any-script),
with the date and the run that produced it.

`bench_jog.sh` exists but is not part of `regenerate_all.sh` yet, and its numbers are not
published. The five-run tracking spread in `results/runs_2026-10-31/` is made with
`bench_tracking.sh`, one run per CSV, separately from `regenerate_all.sh`.

`record_gifs.sh` makes `docs/assets/hero.gif`, `tracking.gif` and `jogging.gif`: it starts the
simulator (through `lib/sim_session.sh`, which takes the shared Gazebo lock), runs
`ros2 run ur5e_teaching_bench record_mode --scene hero|tracking|jogging` to record camera frames
and controller state, then `compose_gifs.py` draws the panels, captions, push arrow, traces and
live numbers from that data. It fails if a GIF is wider than 640 px, larger than 3 MB or longer
than 15 s. `COMPOSE_ONLY=1` with `RAW_DIR` re-composes saved takes without the simulator.
